# Kedai Kopi Senja

Aplikasi pemesanan menu sederhana menggunakan React, Vite, dan Tailwind CSS.

## Cara menjalankan
1. Pastikan Node.js sudah terpasang.
2. Buka terminal di folder `kopi-senja`.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang muncul di terminal.

## Fitur
- Filter kategori menu.
- Buka/tutup detail tiap menu.
- Menu yang tidak tersedia tidak bisa ditambahkan.
- Ringkasan jumlah dan total harga otomatis.
- Validasi nama, nomor meja, dan pesanan.
- Form dan keranjang dikosongkan setelah pesanan terkirim.
